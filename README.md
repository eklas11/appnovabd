# 🛍️ App Nova BD

Bangladesh's trusted digital marketplace for premium apps, templates, source codes, scripts, eBooks & downloadable files.

🌐 **Live:** [appnovabd.onrender.com](https://appnovabd.onrender.com/)

---

## ✨ Features

- 📱 **Mobile-First PWA** — Install as native app
- 💳 **Multi-Payment** — bKash, Nagad, Rocket, Upay, Binance, USDT
- 🔐 **Firebase Auth** — Email/Password + Google Sign-In
- 💰 **Wallet System** — Deposit, purchase, refund
- 🔗 **Product Share** — WhatsApp, Facebook, Telegram
- 🎯 **Deep Linking** — Shareable product URLs
- 🔍 **SEO Optimized** — Product schema, OG tags, sitemap
- ⚡ **Real-time Sync** — Firebase Realtime Database
- 🎨 **Modern UI** — Blue + Amber design system
- 🚀 **Instant Download** — Google Drive / Dropbox auto-convert

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript
- **Backend:** Firebase (Auth + Realtime DB)
- **Hosting:** Render
- **CDN:** Cloudflare (recommended)
- **Icons:** Inline SVG
